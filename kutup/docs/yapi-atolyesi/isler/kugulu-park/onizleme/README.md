# Kuğulu Park önizlemesi v1

Bu dosyalar uygulama görüntüsü değildir. Mevcut iso.js / kit.js ilkelleriyle, katalog ve oyun bağlantısı eklemeden üretilmiş düşük ayrıntılı hacim denemesidir.

- yakin.svg / yakin.png: gündüz, havuz ve ana işlevlerin yerleşim önerisi.
- gece.svg / gece.png: sade gece ton/aydınlatma önerisi; gerçek aydınlatma projesi değil.
- olcek.svg / olcek.png: mevcut ev ve temsilî insan yanında aynı fiziksel oyun ölçeği.

Kaynak fotoğraflar tek tek ölçülmedi; 28 × 24 m sınırı oyun tasarımı önerisidir. Tam kontur, kotlar, heykel biçimleri, kafe ve oyun donatısı ayrıntıları nihai üretim değildir. Ağaçlar ve çitler ayrıntı bütçesi nedeniyle sade; yakın modelde derinlik sırası, dokular ve mevsimler ayrıca tamamlanır. Çizimdeki renkler yalnız izole malzeme denemesidir; ürün arayüz jetonları değiştirilmedi.

Yeniden üretim: node docs/yapi-atolyesi/isler/kugulu-park/onizleme/preview.mjs
